import { Card, CardGrid, LinkCard } from '@astrojs/starlight/components';

Queries are C#: small [delegate fragments](/fallen-8-core/delegates/) compiled at runtime, or
precompiled stored queries. That is a deliberate choice for the era of code-generating agents:
an agent emits a C# fragment, the engine compiles and runs it in-process at full speed, with no
query-language layer in between.

## Key features

<CardGrid>
	<LinkCard title="Graph model" href="/fallen-8-core/graph-model/" description="A directed property graph; typed properties on vertices and edges, all mutation through a serialized transaction queue." />
	<LinkCard title="Delegates, not a query language" href="/fallen-8-core/delegates/" description="Filters and cost functions are runtime-compiled C# fragments; the defining design decision." />
	<LinkCard title="Path finding" href="/fallen-8-core/path-finding/" description="Shortest and weighted paths with delegate filter and cost functions (BLS, Dijkstra)." />
	<LinkCard title="Subgraphs" href="/fallen-8-core/subgraphs/" description="Extract a pattern-matched subset as a standalone graph, recalculate it when the source changes, nest and persist it." />
	<LinkCard title="Graph analytics" href="/fallen-8-core/graph-analytics/" description="PageRank, connected components, communities, degree centrality, triangle counting, with optional property write-back." />
	<LinkCard title="Stored queries" href="/fallen-8-core/stored-queries/" description="Register a vetted, compiled query once and invoke it by name; no dynamic code at call time." />
	<LinkCard title="Indexes" href="/fallen-8-core/indexes/" description="Dictionary, range, fulltext, spatial R-Tree, and vector kNN, all as plugins." />
	<LinkCard title="Vector search" href="/fallen-8-core/vector-search/" description="Exact k-nearest-neighbour over float[] embeddings (cosine, dot product, L2)." />
	<LinkCard title="Semantic traversal" href="/fallen-8-core/semantic-traversal/" description="Embeddings as element state; a code-free semantic block steers paths and subgraphs by similarity." />
	<LinkCard title="Semantic layer" href="/fallen-8-core/unstructured-ingestion/" description="Documents in, graph out: PDFs, Office files and markdown become Document, Chunk and deduplicated Entity vertices, found by fused semantic plus exact-token search and traversable like everything else." />
	<LinkCard title="Bulk import/export" href="/fallen-8-core/bulk-import-export/" description="Stream whole graphs as newline-delimited JSON that round-trips exactly." />
	<LinkCard title="Live change feed" href="/fallen-8-core/change-feed/" description="Committed mutations as Server-Sent Events, in commit order, with in-band resync." />
	<LinkCard title="Save games" href="/fallen-8-core/save-games/" description="Checkpoints tracked by a registry that drives startup, on top of a write-ahead log." />
	<LinkCard title="Namespaces" href="/fallen-8-core/namespaces/" description="Many isolated graphs in one Fallen-8, addressable under /ns/{name}/." />
	<LinkCard title="Observability" href="/fallen-8-core/observability/" description="Opt-in Prometheus and OTLP metrics and traces, a graph-shape snapshot, and health probes, plus a multi-tenant consumer stack." />
	<LinkCard title="REST API" href="/fallen-8-core/rest-api/" description="A versioned HTTP surface with an OpenAPI document and an interactive Scalar reference." />
	<LinkCard title="Plugins" href="/fallen-8-core/plugins/" description="Indices, algorithms, and services are all discovered plugins." />
	<LinkCard title="Plugin registration" href="/fallen-8-core/plugin-registration/" description="Add runtime algorithm and graph-function plugins by authoring C# source instead of uploading a DLL." />
	<LinkCard title="F8 Studio" href="/fallen-8-core/studio/" description="A browser UI to browse, query, visualize, and author the C# delegates, with a natural-language assist." />
	<LinkCard title="MCP server" href="/fallen-8-core/mcp-server/" description="A Model Context Protocol surface so AI agents call Fallen-8 as typed tools; read-only by default, tiered writes, three auth modes." />
	<LinkCard title="Security" href="/fallen-8-core/security/" description="Optional all-or-nothing API key; dynamic code execution is always on, so set a key before exposing the service off-box." />
