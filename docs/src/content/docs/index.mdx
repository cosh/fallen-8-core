Queries are C#: small [delegate fragments](/delegates/) compiled at runtime, or
precompiled stored queries. That is a deliberate choice for the era of code-generating agents:
an agent emits a C# fragment, the engine compiles and runs it in-process at full speed, with no
query-language layer in between.
